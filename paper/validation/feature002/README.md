# Feature 002 Validation Bundle

This directory is generated by:

```powershell
python -m jatibarang_ccus.infrastructure.validation `
  --assumptions data/jatibarang/case_study_assumptions.json `
  --output paper/validation/feature002
```

`artifact_manifest.json` is the machine-readable verdict and hash ledger. The
default net-value proxy result is retained separately as
`rational_zero_selection.json`. The accepted low/base/high results use a mandatory
W01 minimum-cost fixture across the complete unfiltered 20-well candidate library so
that physical, solver, allocation, and supply-comparison behavior can be validated
without presenting the analytic Phase 1 proxy as final integrated economics.

The costs are screening correlations, not Indonesian vendor quotations or FEED
estimates. The exclusion layer is public screening-proxy data, not a field survey.
