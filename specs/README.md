# Feature Specs

This directory is managed manually for this solo Spec Kit project. The feature
numbering is stable and matches the intended implementation order.

Feature 001 (`001-subsurface-surrogate`) is implemented and mechanically promoted.
Its scientific verdict remains conditional under the documented five-case,
inventory-approximation, and extended-horizon caveats. Downstream modules may depend
on its stable trained-range flags, production deltas, inventory series, provenance,
and checkpoint metadata.

Feature 002 (`002-pipeline-optimizer`) is implemented and mechanically validated with
the pinned 20-candidate route library, continuous hydraulics, multi-source fixtures,
and low/base/high pipeline-versus-trucking evidence. Its costs remain screening
correlations; Feature 005 now consumes it through real surrogate demand/value adapters.

Feature 003 (`003-facility-model`) is implemented and validated with typed dedicated-
skid contracts, exact equipment/well/portfolio reconciliation, a mass-based loss
ledger, and eight converged DWSIM cases. The evidence manifest records separate
mechanical and engineering `PASS` verdicts. Its equipment costs remain screening
correlations rather than FEED or vendor estimates.

Feature 004 (`004-economic-engine`) is implemented and mechanically promoted with
typed batch/raw-cost contracts, annual cash flows, dual storage reconciliation,
gas/carbon revenue, deterministic uncertainty bounds, three parametric fiscal modes,
IRR/payback/break-even metrics, and four pinned carbon-price cases. Its saved 36-case
reference batch and warmed 200 x 4 x 3 benchmark pass. These are screening-grade
economic sensitivities, not exact PSC or final-paper results.

Feature 005 (`005-screening-api`) is implemented as the production integration layer.
It replaces the analytic candidate-response proxy on `/screen`, shares one event
pipeline between synchronous and SSE responses, batches and deduplicates Feature 001,
runs per-price Feature 002 selection, evaluates Feature 003 only for selected wells,
and sends raw pipeline/facility/trucking ownership through Feature 004. Focused and
complete regression suites pass. The fixed MRST-derived demo/full preset payloads are
not yet materialized, so the saved preset-promotion evidence is honestly `BLOCKED`
without a fabricated result. Feature 007 still owns A/B/C execution and paper-facing
scientific promotion. A cache-only path now supports Feature 007 downstream
assignment re-solves while explicitly recording zero surrogate calls.

Feature 006 (`006-frontend`) is implemented as a Vite/React screening workbench over
the typed APIs. It includes the complete compose/run/explore workflow, a real-case
offline result, a physically proportioned 64 x 64 x 1 reservoir renderer, independent
scene layers, accessible split panes, and an APECX Paper Results study. It disables
unavailable fields and never substitutes an unrelated plume or relabeled scalar. The
workbench now boots at an offline Earth globe, imports OSM routing/context, accepts a
distinct derived MRST reservoir catalog for W01-W20, and preserves retained top-K
dynamic fields through memo-v4 spatial archives.

Feature 007 (`007-paper-figures`) has a deterministic canonical-bundle builder,
verifier, freeze guard, read-only API, exact Arm B design, reservoir comparison
payload, 20 independent plus 20 correlated Arm C field assignments, cache-only
assignment x carbon-price orchestration, and one script per Figure 1-8. The current
`working` bundle verifies its
present hashes but remains partial and unfrozen: scenario count zero, mechanical
`BLOCKED`, scientific `NOT_RUN`. Figures 1, 2, 3, and 6 are ready; Figures 4, 5, 7,
and 8 and all locked A/B/C results remain blocked. No submitted/full bundle exists.
